# LIMINO

LIMINO is an interactive brand web experience for a five-channel pneumatic boundary system.

## Files

- `index.html` - main single-page website
- `limino_hero_optimized.jpg` - hero background image
- `limino_og_card.jpg` - social preview image
- `assets/limino-logo.svg` - logo asset
- `assets/deep_focus_models.js` - embedded 3D model assets

## GitHub Pages

This project is a static site. Enable GitHub Pages from the repository root and open the generated Pages URL.
